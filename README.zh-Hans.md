# Compositor

Adobe Photoshop 太贵，GIMP 这类工具又不够顺手，让我进不了状态。所以我做了 Compositor。

目标是做一个功能齐全、完全免费且开源的图像编辑器。我以前用 Photoshop 做合成和后期，所以 Compositor 就是围绕这套工作流搭建的——该有的工具都有，能做出像素级的成品。

因为是开源的，你可以直接下载 Xcode 工程，按自己的工作流增删改任何功能。

## 安装

### 下载
从 [robbietilton.com/compositor](https://robbietilton.com/compositor) 获取 Compositor，或直接从 [GitHub Releases](https://github.com/robbietilton/Compositor/releases/latest) 下载最新版本。

### Homebrew

```sh
brew install --cask robbietilton-compositor
```

## 功能

### 图层
- 图层与图层组，支持不透明度和 Photoshop 全套混合模式（顺序一致）——图层组的不透明度会压暗其中所有内容
- 图层蒙版：可在画布任意位置绘制、填充、反相、模糊和羽化，不受图层自身像素范围限制；可链接或取消链接蒙版，单独变换蒙版
- 剪贴蒙版与图层组蒙版
- 调整图层：色相/饱和度、色阶、曲线、曝光度、渐变映射、颗粒、黑白、色彩平衡、反相、高斯模糊、动感模糊和杂色
- 图层效果：描边、投影、颜色叠加、内阴影、外发光和内发光，由 GPU 渲染，随时可编辑
- 向下合并、合并图层、合并图层组（⌘E）
- 复制、原地重命名、拖放调整顺序与嵌套；按住 Option 拖动可复制；图层面板有右键菜单
- 复制粘贴整个图层与图层组（无选区时 ⌘C/⌘V），项目内、跨项目皆可，也可在项目之间拖动

### 变换
- 非破坏性移动、缩放、旋转与翻转——无论缩到多小，图像都保持完整分辨率
- 自由变形（按住 ⌘ 拖动控制柄），按住 Shift 锁定轴向
- 同时变换多个图层或整个图层组
- 吸附到画布与图层的边缘和中心，并显示参考线
- 位置、大小、缩放与角度的精确数值，可用方向键步进
- 水平、垂直翻转图层与翻转画布

### 选区
- 矩形与椭圆选框、自由手绘与多边形套索，以及魔棒工具——魔棒按颜色选择，对象会描出你点击的轮廓（Tab 切换）
- 选择主体，以及可对任意选区执行扩展、收缩和羽化
- 添加到选区、从选区减去、移动选区轮廓，或移动并复制其中的像素
- 把图层像素或蒙版载入为选区
- 内容识别填充，还能把图像扩展到边缘之外

### 绘画与修饰
- 画笔支持大小、硬度、不透明度和平滑，可绘画或擦除（B 和 E），按住 Shift 画直线
- 污点修复画笔（内容识别）
- 仿制图章，可对齐或不对齐，可从单个图层或所有图层取样
- 模糊工具，作用于像素或蒙版
- 渐变工具与形状工具（矩形、圆角矩形、椭圆和直线），保持可编辑而非栅格化
- 文字工具（T）：在可拖动、可缩放的段落框里原地多行编辑；字体、大小、颜色、对齐与间距在工具头部设置；可变换文字并用作剪贴蒙版
- 吸管与完整的颜色选择器

### 调整与滤镜
- 相机原始数据滤镜：光线、颜色、曲线、混色器、颜色分级、细节、光学和几何，面板就在画布旁边
- 色阶（含自动）、曲线、色相/饱和度、曝光度、渐变映射、颗粒、黑白、色彩平衡和反相
- 高斯模糊与动感模糊，可溢出图层边缘
- 添加杂色、晕影、泛光／光晕、色调对比、镜头校正和移除背景
- 实时预览，有选区时只作用于选区

### 画布与文件
- 标签页中同时打开多个项目
- 命令面板（⌘F）：按名称搜索所有菜单命令与工具，像 Raycast 或 Obsidian 那样，按 Return 执行
- 仅画布（F）：整屏黑底上只留画布，所有面板收起；再按 F 恢复
- 标尺（⌘R）、从标尺拖出的参考线、可调间距与细分的布局网格，以及对齐到参考线、网格、图层和文档边界
- 裁剪支持吸附，比例包括 3:4 和 9:16，按住 Option 对称裁剪；有选区时以选区为起点
- 画布大小、图像大小和修整
- 缩小时锐利的高品质降采样，放大时显示像素网格
- 导入 JPEG、PNG、HEIC、TIFF、SVG、相机原始数据（先经显影步骤）以及 Photoshop PSD 和 PSB（8 位 RGB；不支持 CMYK）。Photoshop 的图层组、蒙版、混合模式、填充矩形／椭圆和简单横排文字保持可编辑；其他矢量与竖排文字转为像素。应用任何更改之前都会先显示转换报告。
- 大文档：内存预算随你的 Mac 扩展；过大的 Photoshop 文件无法打开时，改为把其图层裁剪到画布范围
- 导出 JPEG 并实时预览（⇧⌥⌘S）；合并拷贝
- 项目保存期间可继续工作
- 全程 Photoshop 风格快捷键，可在「编辑 > 键盘快捷键」中重新映射
- 拖动数值标签即可拖动调整其值，与 Photoshop 一致
- 自动更新，已签名并公证

### 与 AI 智能体协作
- AI 智能体和脚本可以直接创建和编辑项目：`.comp` 就是一组 PNG 图层加一份清单文件，打开的项目会随着写入实时更新。参见[编写 Compositor 项目](docs/writing-comp-files.md)

## 系统要求

- Apple 芯片 Mac，macOS 26.0 或更高版本
- Xcode 26 或更高版本（从源码构建时）

## 构建

打开 `Compositor.xcodeproj`，运行 **Compositor** scheme。

## 发布

`scripts/release.sh` 会构建 Release 版本，用 Developer ID 签名、公证并装订票据，然后打包成 `dist/Compositor-<version>.dmg`。

它需要以下东西，且都不放在本仓库中：

- 登录钥匙串中的 **Developer ID Application** 证书
- 通过 `xcrun notarytool store-credentials "compositor-notary" …` 保存的公证凭据
- [`create-dmg`](https://github.com/create-dmg/create-dmg)（`brew install create-dmg`）
